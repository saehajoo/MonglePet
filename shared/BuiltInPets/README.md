# 플랫폼 공통 내장 펫

`Mongle.monglepet/`은 macOS 최신 작업에서 확정한 내장 몽글이의 데이터 전용 기준본이다. Windows는 `apps/macos`의 asset catalog를 직접 참조하지 않고 이 디렉터리를 앱 출력과 publish에 포함한다.

- 예약 ID: `kr.mapleroom.monglepet.builtin.mongle`
- 콘텐츠 버전: `1.0.3`
- 제작자: `운영자`
- 13개 모션, 53프레임, 150×150px 셀
- 원본 외부 패키지 SHA-256: `d33c6265475969278012b96d4906311d73891c68b1b13c8e0464ac0bbaf47f9b`

schema-v10 `recommended-profile.json`은 운영체제에 독립적인 행동·입력 없음·세 모드의 독립 이동·쓰다듬기·말풍선과 펫 표시 값을 포함한다. 현재 표시 기본값은 50%, 클릭 통과·겹침 투명화 켬, 겹침 불투명도 45%, 픽셀 표시 끔, 불투명도 100%다. 화면 위치·디스플레이·모든 펫 공통 이동 범위는 포함하지 않는다. 기본 앱 사용 규칙은 없으며 플랫폼별 식별자를 임의로 추가하지 않는다.

외부 패키지의 사용자 ID와 이름은 내장 예약 메타데이터로 바꿨고 펫 콘텐츠 버전은 `1.0.3`으로 승격했다. 앱 호환성 `1.3.2`, 이미지 픽셀과 모션·프레임 값은 기준 패키지에서 변경하지 않는다.
