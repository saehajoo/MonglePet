# Windows 말풍선 런타임과 설정 UI

## 상태

- 상태: completed
- 생성일: 2026-08-09
- 마지막 갱신: 2026-08-09

## 목표

- macOS에서 확정된 펫별 말풍선 동작을 Windows 네이티브 앱에 같은 결과로 구현한다.
- 행동 대사 우선순위, 주기 대사 timer, 테마와 화면 경계 배치를 Windows 오버레이에 연결한다.
- 사용자가 Windows 설정 화면에서 말풍선 대사·정책·테마·배치를 편집할 수 있게 한다.

## 범위

- 테스트 가능한 말풍선 scheduler와 행동·주기 대사 선택 런타임
- 행동 루틴 전환, 재우기·잠금·절전·펫 전환 생명주기 연결
- 입력을 받지 않는 별도 Win32 HWND와 WinUI 3 XAML Island 기반 말풍선 표시
- 자동·위·아래 배치, 좌우 오프셋·간격, 모니터 작업 영역 경계 보정과 꼬리 기준점
- 대사 추가·수정·삭제, 주기 정책, 행동 전환 정책, 테마와 배치 설정 UI
- 관련 단위 테스트와 문서 동기화

## 제외 범위

- 음성 합성, 네트워크·AI 대화와 말풍선 내부 상호작용
- 외부 글꼴·스크립트·테마 플러그인
- 실제 혼합 DPI·장시간 성능 수동 QA

## 열린 질문

- 없음

## 결정사항

- 기존 schema-v10 `PetSpeechSettings`를 그대로 사용하고 새 저장 스키마를 만들지 않는다.
- 말풍선 본체는 펫 HWND와 독립된 non-activating·click-through Win32 HWND에 WinUI 3 `DesktopWindowXamlSource`를 연결해 표시한다.
- scheduler와 배치 계산은 Win32·XAML에서 분리해 `MonglePet.Settings` 단위 테스트에서 검증한다.
- 행동 대사는 주기 대사보다 우선하며 이동·쓰다듬기 애니메이션은 행동 루틴 전환으로 취급하지 않는다.
