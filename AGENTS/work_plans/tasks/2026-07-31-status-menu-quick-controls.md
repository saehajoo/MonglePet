## 목표

- 메뉴 막대 상태 메뉴에서 현재 펫과 자주 쓰는 표시 설정을 빠르게 확인하고 제어한다.
- 기본 캐릭터에 한정된 `몽글이` 제어 문구를 모든 사용자 펫에 맞는 `펫` 문구로 바꾼다.

## 범위

- 현재 선택된 펫 이름 표시
- 펫 깨우기·재우기
- 클릭 통과 체크 상태 확인과 전환
- 마우스가 있는 현재 화면으로 펫 가져오기
- 설정과 앱 종료 진입점 유지
- 메뉴·오버레이 연결 단위 테스트와 수동 QA 항목

## 제외 범위

- 상태 메뉴에서 펫 선택
- 자동·수동 행동 모드, 행동 루틴과 이동 모드 변경
- 상태 메뉴 전용 설정 저장소 또는 새 설정 스키마

- 없음

## 결정사항

- 클릭 통과는 기존 전역 overlay 설정을 단일 원본으로 사용한다.
- `현재 화면`은 상태 메뉴 명령을 실행한 시점의 마우스 포인터가 있는 디스플레이다.
- 화면으로 가져오기는 현재 펫 크기를 유지하고 해당 화면의 기본 우하단 위치로 옮긴다.
- 명시적으로 옮긴 위치는 이동 모드와 관계없이 사용자가 선택한 기준 위치로 저장한다.
