# 말풍선 테마 커스텀

## 상태

- 상태: in_progress
- 생성일: 2026-07-30
- 마지막 갱신: 2026-07-31

## 목표

- 1차 말풍선 기능이 안정화된 뒤 펫의 분위기에 맞는 표시 테마를 사용자가 구성하고 선택적으로 공유할 수 있게 한다.

## 범위

- 배경·글자 색상과 불투명도
- 글자 크기, 안쪽 여백과 모서리 반경
- 말풍선 꼬리 표시와 방향
- 접근 가능한 대비와 기본값 복구
- 펫별 저장·미리보기와 권장 프로필 공유 범위

## 제외 범위

- 임의 SwiftUI·HTML·스크립트 테마
- 외부 글꼴 파일과 실행 코드
- 애니메이션 효과 편집기

## 열린 질문

- 없음

## 결정사항

- 데이터 전용 값만 허용하고 외부 코드나 테마 플러그인을 허용하지 않는다.
- 동작 줄이기, 명암 대비와 글자 가독성을 우선한다.
- 시스템·크림·밤·민트·복숭아 색상 preset과 사용자 지정 배경·글자 색상을 함께 제공한다.
- 사용자 지정 색상은 WCAG AA 일반 텍스트 기준인 4.5:1 이상의 대비를 만족해야 저장할 수 있다.
- 글자 크기, 단일 안쪽 여백, 모서리 반경, 배경 불투명도와 꼬리 표시·좌/중앙/우 정렬을 펫별로 저장한다.
- 기존 schema-v7 사용자는 현재 모양과 가까운 시스템 색상, 14pt, 기본 여백·모서리와 꼬리 없음으로 마이그레이션한다.
- 테마는 권장 프로필에 포함하되 받는 사용자가 권장 설정 적용을 선택한 경우에만 로컬 펫 설정으로 복사한다.
