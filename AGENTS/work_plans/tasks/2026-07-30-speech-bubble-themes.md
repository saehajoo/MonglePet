# 말풍선 테마 커스텀

## 상태

- 상태: planned
- 생성일: 2026-07-30
- 마지막 갱신: 2026-07-30

## 목표

- 1차 말풍선 기능이 안정화된 뒤 펫의 분위기에 맞는 표시 테마를 사용자가 구성하고 선택적으로 공유할 수 있게 한다.

## 범위

- 배경·글자 색상과 불투명도
- 글자 크기, 안쪽 여백과 모서리 반경
- 말풍선 꼬리 표시와 방향
- 접근 가능한 대비와 기본값 복구
- 펫별 저장·미리보기와 권장 프로필 공유 범위

## 제외 범위

- 임의 SwiftUI·HTML·스크립트 테마
- 외부 글꼴 파일과 실행 코드
- 애니메이션 효과 편집기

## 열린 질문

- 시스템 preset과 완전 사용자 지정 값을 함께 제공할지 1차 말풍선 QA 후 결정한다.

## 결정사항

- 데이터 전용 값만 허용하고 외부 코드나 테마 플러그인을 허용하지 않는다.
- 동작 줄이기, 명암 대비와 글자 가독성을 우선한다.

## 작업 순서

- [ ] 1단계: 1차 말풍선 실제 앱 QA와 요구사항 확정
- [ ] 2단계: 테마 Domain·저장·공유 schema 설계
- [ ] 3단계: 설정 미리보기와 런타임 적용
- [ ] 4단계: 자동·수동 접근성 검증

## 검증 방법

- 테마 저장·복원과 이전 schema 기본값
- 밝은·어두운 화면의 대비와 긴 대사 레이아웃
- `.monglepet` 권장 프로필 내보내기·가져오기 왕복

## 진행 로그
