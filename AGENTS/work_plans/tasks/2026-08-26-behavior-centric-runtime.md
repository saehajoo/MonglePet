## 결정사항

- 애니메이션은 프레임 자산으로 남고 행동 단계만 애니메이션을 참조한다. 사용자 기능은 행동 ID를 참조한다.
- 이동 행동은 기본 행동과 분리된 표시 계층이다. 이동 계층이 실제 표시되는 동안 가려진 기본 행동 scheduler를 pause한다. 자동·직접 행동은 단계·반복·사이클 남은 시간과 프레임 위치를 보존하고, 랜덤 행동은 D-106에 따라 이동 시작 때 현재 행동을 중단해 shuffle bag의 다음 행동을 첫 cycle로 준비한다. 이동 시작·종료 또는 해석 행동 ID 변경 때만 스케줄러를 갱신한다.
- 쓰다듬기 행동은 가장 높은 표시 우선순위의 일회성 상호작용으로 실행한다.
- 이동·쓰다듬기 행동 변화는 행동 시작 말풍선을 발생시키지 않는다.
- 입력 없음 규칙은 프로필당 하나만 두고 사용 여부로 제어한다. 앱 규칙은 앱 식별자당 하나만 둔다.
- 자동 동작 우선순위는 개별 숫자 대신 `표시 및 이동`, `입력 없음 규칙`, `앱 사용 규칙` 세 항목의 위에서 아래 목록 순서로 해석한다.
- 일치한 앱·입력 없음 규칙이 `표시 및 이동`보다 앞이면 현재 위치에서 이동을 멈추고, 규칙 해제 후 현재 위치를 기준으로 다시 시작한다. `표시 및 이동`이 앞이면 이동을 유지한다.
- 입력 없음 규칙은 첫 생성 버튼 대신 항상 보이는 사용 토글로 켜고 끄며 시간·행동은 별도 `변경` 버튼으로 저장한다. 입력 없음 섹션을 앱 사용 규칙 추가보다 먼저 표시한다.
- 입력 없음 임계값은 `1...86,400초` 정수로 편집하며 기존 `idleAtLeast.milliseconds` 저장 계약에는 초 값의 1,000배를 기록한다.
- 기존 애니메이션 직접 참조는 같은 애니메이션별 단일 단계 행동을 중복 없이 생성해 변환한다.
- 릴리스와 새 내장 펫 교체는 새 펫 파일을 받은 뒤 별도 완료 단계로 진행한다.
- 랜덤은 애니메이션 단계가 아니라 사용자가 고른 행동 단위를 섞고, 한 bag에서 각 행동을 한 번씩 실행한다.
- 자유 이동 랜덤 시간은 목표 도착 시 한 번만 추첨하며 기존 시간은 최댓값으로 유지한다.
- 10~200% 크기는 기존 pt 저장을 유지하고 25% 미만에서 찾기·드래그 복구 안내를 제공한다. `설정 대상 펫`과 `펫 깨우기`는 별도 행으로 두고 세부 표시·정지 반경·방향별 행동도 접지 않고 항상 보여준다.
- schema-v14에서 각 이동 방식은 필요한 수치·시간 방식·행동을 독립 소유하며 도망가기의 평상시 자유 이동도 일반 자유 이동 값을 재사용하지 않는다.
- 권장 프로필 v10과 앱의 패키지 저장은 모든 휴대 펫 옵션을 포함한다. 화면 좌표·디스플레이·모든 펫 공통 이동 범위·깨움·로그인 실행은 제외하고 앱 규칙만 별도 선택한다. v9 이하 적용은 현재 표시 설정을 유지한다.
- 애니메이션 복제는 하나의 진입점에서 복사본 편집 화면을 열고, 행동 연결은 해당 화면의 공통 선택을 저장할 때만 적용한다. 취소 시 복사본을 되돌리고 오류는 하단 작업 영역에서 항상 보이게 한다.
- 행동 실행의 평상시 선택은 `하나 선택`과 `랜덤 선택`으로 제한하고 입력 없음·앱 규칙 평가는 선택 방식과 독립적으로 항상 수행한다. 기존 `automatic`은 기본 행동 하나 선택, `manual`은 기존 직접 선택 행동 하나 선택, `random`은 기존 선택 목록으로 마이그레이션한다.
- schema-v14의 `manual`·`random` 프로필에서 보관만 하던 활성 규칙이 업데이트 직후 갑자기 실행되지 않도록 v15 마이그레이션은 해당 프로필의 규칙을 비활성화한다. 규칙 값과 우선순위는 보존하고 사용자가 `규칙 설정`에서 다시 켤 수 있게 한다. 기존 `automatic` 프로필의 규칙 사용 상태는 그대로 유지한다.
- 규칙 조건이 일치하면 평상시 고정·랜덤 선택보다 우선한다. 실제 이동과 규칙의 충돌만 `이동`, `입력 없음 규칙`, `앱 사용 규칙` 순서로 판정하고 평상시 행동은 우선순위 목록에 넣지 않는 최종 fallback이다.
- 규칙이 랜덤 평상시 행동을 중단하면 현재 랜덤 cursor를 버리고 shuffle bag의 다음 행동을 준비한다. 규칙 종료 뒤 이전 행동의 나머지를 이어서 표시하지 않고 다음 행동의 첫 단계·첫 프레임부터 시작한다.

## 검증 방법

- 로컬 schema-v1~v15와 권장 프로필 v1~v11 fixture 마이그레이션·왕복
- 같은 애니메이션의 자동 생성 행동 중복 방지와 참조 복구
- 고정/랜덤 평상시 선택, 단일 입력 없음과 앱 규칙 종류 우선순위 Domain 테스트
- v14 자동/직접/랜덤 프로필의 v15 평상시 선택 마이그레이션과 dormant 규칙 비활성화
- 권장 프로필 v10→v11 마이그레이션과 macOS 내보내기·가져오기 왕복
- 고정·랜덤 평상시 행동에서 입력 없음·앱 규칙이 공통 적용되고 규칙 해제 뒤 올바른 fallback으로 돌아가는지 확인
- 랜덤 평상시 행동을 규칙이 중단할 때 다음 shuffle bag 행동이 첫 프레임부터 시작하는지 확인
- 이동 중 같은 행동 ID의 재시작 방지, 방향 행동 변경, 정지 복귀와 쓰다듬기 우선순위
- 이동 33ms cadence 중 행동 timer·playback 변경이 상태 변경 횟수로 제한되는지 확인
