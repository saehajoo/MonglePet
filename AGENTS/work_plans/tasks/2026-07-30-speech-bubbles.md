# 펫별 말풍선 1차 기능

## 상태

- 상태: in_progress
- 생성일: 2026-07-30
- 마지막 갱신: 2026-07-31

## 목표

- 사용자가 현재 펫에 짧은 대사를 등록하고 일정 간격 또는 행동 루틴 진입 시 말풍선으로 표시할 수 있게 한다.
- 말풍선은 클릭을 가로채지 않고 펫 이동을 따라가며 화면 경계 안에서 표시한다.
- 재우기·잠금·절전 중에는 표시와 timer를 중지하고 유휴 상태에서 불필요한 polling을 하지 않는다.

## 범위

- 펫별 말풍선 사용 여부, 대사 목록과 주기 간격
- 대사별 표시 시간과 `periodic` / `sequence` 표시 조건
- settings schema-v7과 schema-v6 순차 마이그레이션
- 행동 루틴 진입·주기 timer 기반 말풍선 런타임
- 클릭 통과 child panel과 화면 경계 보정
- 별도 `말풍선` 설정 탭의 추가·수정·삭제 UI
- 권장 프로필 schema-v4와 schema-v1·v2·v3 호환
- 내보내기·가져오기 공통 요약

## 제외 범위

- AI 생성 대화, 네트워크 또는 앱·화면 내용 기반 대사
- 말풍선 클릭, 버튼과 입력 필드 같은 상호작용
- 사용자 지정 색상·글꼴·꼬리·모서리·불투명도
- 펫 패키지 manifest의 독립 대사 파일
- 이동·쓰다듬기·깨우기 전용 세부 조건

## 결정사항

- 말풍선 설정은 행동 루틴과 함께 펫별 `BehaviorProfile`에 저장한다.
- 기본값은 사용 안 함과 빈 대사 목록이며 시스템 고정 대사를 자동으로 추가하지 않는다.
- 주기 대사는 하나의 일회성 timer만 사용하고 같은 대사의 연속 선택을 가능한 경우 피한다.
- 행동 대사는 실제 행동 루틴 ID가 바뀐 시점에만 표시하며 이동 애니메이션 덮어쓰기에는 반응하지 않는다.
- 말풍선 창은 클릭을 통과하는 non-activating child panel로 만들고 표시 중에만 유지한다.
- 제작자가 공유할 대사와 규칙은 선택적 권장 프로필에 포함하며 기기별 위치·테마는 포함하지 않는다.
- 1차 스타일은 시스템 색상 기반의 고정 테마로 두고 테마 커스텀은 별도 후속 작업으로 진행한다.
