# 펫 가져오기 호환성 차단과 검토 화면 단순화

## 상태

- 상태: windows_implementation_complete_qa_pending
- 생성일: 2026-09-05
- 마지막 갱신: 2026-09-05

## 목표

- 제작자가 구성한 행동·이동 설정을 현재 앱에서 재현할 수 없는 펫을 최소 설정으로 조용히 추가하지 않는다.
- 실제 최소 앱 버전이 부족하면 설치를 막고 공식 다운로드 페이지로 안내한다.
- 제작자 설정이 손상된 패키지는 불완전한 펫으로 추가하지 않고 다시 받도록 안내한다.
- 제작자 설정이 없는 레거시 패키지는 명확한 안내와 함께 기존 최소 설정 호환을 유지한다.
- 가져오기 검토 화면은 핵심 결과만 먼저 보여주고 전체 설정은 `자세히 보기`에서 확인하게 한다.
- macOS 기준 결과와 공통 계약을 확정하고 Windows·웹 서버 후속 구현 지침을 남긴다.

## 범위

- `.monglepet` 앱 호환성 평가와 설치 transaction의 차단 경계
- 제작자 설정 없음·미래 schema·손상 상태의 구분
- 내보내기 `createdWithMonglePetVersion`·`minimumMonglePetVersion` 기록 의미
- macOS 로컬·웹 공통 가져오기 검토 UI
- 관련 단위 테스트, 공통 명세, 결정, 플랫폼 동등성, Windows·서버 인계

## 제외 범위

- 앱 내부 자동 업데이트·다운로드·설치
- `.monglepet` package formatVersion, 로컬 settings schema-v16, 제작자 설정 schema-v12 변경
- 웹 서버 소스 구현·배포
- macOS 앱 버전·빌드 번호 증가와 GitHub Release

## 결정사항

- `createdWithMonglePetVersion`이 현재 앱보다 높은 것만으로는 설치를 막지 않는다.
- package 또는 게시 metadata의 `minimumMonglePetVersion`이 현재 앱보다 높으면 설치를 차단한다.
- 미래 제작자 설정 schema는 앱 업데이트가 필요한 상태로, 읽을 수 없거나 의미상 손상된 제작자 설정은 잘못된 펫 파일로 표시하고 설치를 차단한다.
- 제작자 설정 파일 자체가 없는 레거시 패키지만 안전한 최소 설정으로 추가할 수 있다.
- 업데이트 버튼은 고정된 공식 주소 `https://mapleroom.kr/monglepet/download`를 사용자가 눌렀을 때 기본 브라우저로 연다.
- 전체 제작자 설정 요약과 상세 호환 버전은 기본적으로 접고 핵심 설치 결과와 차단 사유는 항상 표시한다.
- 현재 제작자 설정 schema-v12를 포함한 새 공유 파일의 최소 앱 버전은 해당 schema를 처음 지원한 `1.7.0`으로 기록한다. 다음 앱 버전이 같은 schema를 계속 쓰면 최소 버전을 불필요하게 올리지 않는다.
