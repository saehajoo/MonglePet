# 웹 커뮤니티 인계 지침

## 상태

- 상태: completed
- 생성일: 2026-07-31
- 마지막 갱신: 2026-07-31

## 목표

- 별도 웹 저장소에서 MonglePet 펫 공유 커뮤니티를 안전하게 시작할 수 있는 자체 완결형 인계 지침을 작성한다.
- 데스크톱 앱과 웹서비스의 저장소·배포·보안 책임을 분리하고 `.monglepet` 계약의 단일 원본을 명확히 한다.

## 범위

- 별도 저장소와 서버 개발·배포 원칙
- 익명 조회·다운로드와 인증 사용자 업로드·댓글 정책
- 데이터 모델과 API 초안
- `.monglepet` upload quarantine·검증·미리보기·게시 흐름
- 라이선스, 신고, 개인정보와 운영 보안
- 단계별 구현 순서와 인계 완료 조건
- 루트 문서 라우팅, 인덱스, 제품·아키텍처·결정 기록 동기화

## 제외 범위

- 실제 웹 저장소 생성
- frontend, API, DB와 worker 구현
- 개인 서버의 기술 스택 확정
- 운영 서버 배포
- 온라인 카탈로그의 데스크톱 앱 연동

## 열린 질문

- 개인 서버 환경과 기존 API 구성은 새 웹 저장소의 Phase W0에서 조사한다.

## 결정사항

- 웹 커뮤니티는 별도 Git 저장소와 배포 체계를 사용한다.
- MonglePet 저장소는 패키지 schema·fixture의 단일 원본으로 유지한다.
- 웹 기술 스택은 기존 개인 서버 환경을 확인한 뒤 확정한다.
- 비회원 다운로드를 허용하고 업로드·댓글·좋아요·신고는 인증을 요구한다.
- 원본 패키지는 서버에서 재검증하고 관리자 승인 전까지 공개하지 않는다.
