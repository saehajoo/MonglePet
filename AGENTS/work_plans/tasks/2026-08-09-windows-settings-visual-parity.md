# Windows 설정 화면 시각적 동등성

## 상태

- 상태: completed
- 생성일: 2026-08-09
- 마지막 갱신: 2026-08-09

## 목표

- macOS 설정 화면의 섹션 구성, 사용자 문구와 현재 펫 미리보기를 Windows 설정 화면에도 반영한다.
- 기존 Windows 기능과 저장 동작은 유지하면서 WinUI에 자연스러운 카드형 설정 화면으로 정돈한다.

## 범위

- Windows `MainPage`의 펫, 일반, 이동, 행동 루틴, 말풍선, 자동 규칙 화면
- 현재 펫 이미지와 이름·제작자·버전·설명·모션 요약 표시
- 이동 방식 선택 카드와 말풍선 테마 미리보기
- 사용자 중심 문구, 도움말과 진단 정보 분리

## 제외 범위

- macOS SwiftUI 화면의 소스나 레이아웃을 그대로 복사하는 작업
- Windows 펫 편집기와 신규 패키지 제작 기능 추가
- 설정 스키마 또는 런타임 동작 변경

## 열린 질문

- 없음

## 결정사항

- macOS와 같은 설정 결과와 정보 순서를 유지하되 Windows에서는 WinUI 카드와 상단 탐색을 사용한다.
- 기술 경로와 런타임 문자열은 기본 설명에서 제거하고 접을 수 있는 진단 정보로 이동한다.
- 현재 펫 미리보기는 활성 `.monglepet` 패키지의 `preview` 이미지를 사용한다.

## 작업 순서

- [x] 1단계: macOS와 Windows 설정 화면 및 데이터 연결점 비교
- [x] 2단계: 공통 카드 스타일, 문구와 일반 설정 정보 구조 정돈
- [x] 3단계: 현재 펫·이동 방식·말풍선 미리보기 구현
- [x] 4단계: 문서 갱신, 전체 테스트와 Debug·Release 빌드 검증
- [x] 5단계: 개발 패키지 업데이트 등록과 실행 확인

## 검증 방법

- Windows 테스트 전체 실행
- x64 Debug 앱 빌드
- x64 Release MSIX 패키지 생성
- 개발 패키지 업데이트 등록 후 각 설정 탭과 현재 펫 미리보기 확인

## 진행 로그

- 2026-08-09: macOS 설정의 6개 탭, 섹션 문구, 현재 펫 미리보기와 Windows 기존 설정 화면을 비교했다.
- 2026-08-09: 일반 탭을 펫 표시·행동 모드·화면 표시·앱 실행·앱 정보 순서로 정돈하고 개발자용 상태를 접힌 진단 정보로 이동했다.
- 2026-08-09: 활성 패키지의 실제 미리보기와 메타데이터, 네 이동 방식 선택 카드, 펫이 함께 보이는 말풍선 테마 미리보기를 구현했다.
- 2026-08-09: x64 Debug 빌드와 전체 153개 테스트를 통과했다.
- 2026-08-09: 1.0.0.6 x64 Release·MSIX를 생성하고 기존 LocalState를 유지한 개발 패키지 업데이트 등록, 패키지 상태 `Ok`와 앱 프로세스 응답을 확인했다.

## 완료 결과

- Windows 설정 화면이 macOS 설정과 같은 기능 순서와 사용자 중심 문구를 사용한다.
- 펫 탭에서 현재 펫의 실제 이미지, 이름, 제작자, 버전, 설명과 애니메이션 요약을 확인할 수 있다.
- 이동 탭과 말풍선 탭에 설명형 선택 카드와 실제 펫 기반 미리보기가 추가됐다.
- 설정 스키마와 기존 오버레이·행동·이동·말풍선 런타임은 변경하지 않았다.

## 남은 위험 / 후속 작업

- 실제 혼합 DPI와 밝은·어두운 테마의 최종 육안 QA는 전체 기능 QA에서 함께 진행한다.
