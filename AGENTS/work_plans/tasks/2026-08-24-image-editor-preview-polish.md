# 이미지 편집 결과 미리보기와 스크롤 다듬기

## 상태

- 상태: completed
- 생성일: 2026-08-24
- 마지막 갱신: 2026-08-24

## 목표

- 스프라이트 선택 영역과 개별 PNG crop 결과를 실제 저장 프레임처럼 투명 격자와 명확한 경계 안에서 확인한다.
- 확대·축소 컨트롤의 크기를 통일하고 PNG 편집기의 세로 잘림과 스크롤 불가 문제를 해결한다.
- macOS 기준 UI를 확정한 뒤 Windows 편집기 인계 조건을 같은 결과로 갱신한다.

## 범위

- crop·flip 결과 공통 미리보기 캔버스
- 투명 격자, 바깥 캔버스 테두리와 실제 crop 프레임 경계
- 단일 PNG의 상시 결과 미리보기와 다중 PNG 결과 탐색
- 확대·축소 버튼의 동일한 hit area·높이·아이콘 크기
- PNG 편집 본문의 전체 세로 스크롤과 확대 캔버스의 독립 pan
- 스프라이트 원본 비율에 맞는 전체 시트 캔버스 높이와 고정 선택 결과 미리보기
- PNG 원본 자르기 캔버스와 동시에 보이는 고정 결과 패널·독립 설정 스크롤
- macOS 테스트·빌드·실제 화면 검토와 Windows 인계 갱신

## 결정사항

- 결과 미리보기는 새 펫 애니메이션 프레임 미리보기와 같은 투명 격자·캔버스 외곽선 구조를 사용한다.
- 파란 실선은 실제 crop 결과의 전체 프레임 경계를 나타내며 투명 여백도 경계 안에 포함한다.
- 확대 배율이 1×일 때 편집 캔버스가 바깥 페이지 스크롤을 가로채지 않고, 1×보다 클 때만 내부 양축 pan을 제공한다.
- 스프라이트 전체 시트 캔버스는 원본 비율과 창의 사용 가능 높이에 맞추되 최소 편집 높이를 보장한다.
- 스프라이트 선택 결과 미리보기는 오른쪽 상단에 고정하고, 경계·범위·순서·배경 설정만 그 아래에서 독립적으로 스크롤한다.
- PNG 결과 미리보기도 오른쪽 상단에 고정하고 선택 범위와 PNG 목록만 그 아래에서 독립적으로 스크롤한다. 하단 다중 결과 목록은 제거하고 고정 패널의 이전·다음 탐색과 목록의 crop 썸네일로 통합한다.
- 공개 `1.3.0 (5)`는 그대로 보존하고 보정 결과는 `1.3.1 (6)`, 태그 `macos-v1.3.1-preview.1`로 새로 게시한다.

## 검증 방법

- 가로·세로·정사각 crop이 투명 격자 안에 aspect-fit되고 파란 프레임 경계가 잘리지 않는지 geometry 테스트한다.
- 스프라이트 선택 영역과 단일·다중 PNG가 같은 결과 캔버스를 사용하고 flip을 즉시 반영하는지 확인한다.
- 최소 높이 창에서 PNG 본문을 끝까지 스크롤해 목록·파일 추가·가져오기 안내에 접근할 수 있는지 확인한다.
- 1×에서는 바깥 세로 스크롤, 1.5×~8×에서는 이미지 pan과 원본 crop 좌표 보존을 확인한다.
- 확대·축소 버튼의 frame·아이콘·hit area가 같은지 실제 화면에서 비교한다.

## 완료 결과

- 스프라이트 선택 영역과 PNG crop 결과가 같은 투명 격자, 바깥 캔버스 테두리와 파란 실제 저장 범위를 표시한다.
- 단일 PNG도 결과 미리보기를 항상 제공하고 다중 선택은 별도 가로 결과 목록에서 집중 대상을 바꿀 수 있다.
- PNG 편집기는 header/footer를 고정하고 두 열 본문 전체를 세로 스크롤하며, 1×에서 내부 pan을 제거해 바깥 페이지 스크롤과 충돌하지 않는다.
- 확대·축소 버튼의 버튼 frame과 아이콘 frame을 통일했다.
- 스프라이트 전체 시트는 가로·세로 비율과 사용 가능한 창 높이에 맞게 표시되어 넓은 시트의 긴 세로 공백을 만들지 않는다.
- 선택 결과 미리보기는 오른쪽 상단에 계속 보이고, 항목이 늘어나는 설정 영역만 별도로 스크롤된다.
- PNG 편집 중에도 오른쪽 결과가 항상 보여 범위 수정과 결과 확인 사이에 세로 스크롤을 반복하지 않으며, 다중 결과는 같은 고정 패널에서 순환한다.
- D-089, README, 플랫폼 현황, Windows 인계·실행 프롬프트와 배포 보류 문서를 갱신했다.
