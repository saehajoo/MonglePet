## 상태

- 상태: done
- 생성일: 2026-08-08
- 마지막 갱신: 2026-08-08

## 목표

- schema-v10 typed 설정의 사용자 표시 상태와 오버레이 표시 옵션을 WinUI 편집 UI, 로컬 저장소와 Win32/Composition 오버레이에 연결한다.

## 범위

- 마지막 사용자 표시 상태(`awake`, `tuckedAway`) 저장과 시작 시 복원
- 펫 너비 96–384, 기본 투명도 0.10–1.00, 클릭 통과와 픽셀 아트 렌더링의 즉시 적용
- 펫 전환 뒤에도 현재 표시 설정 유지
- 설정 저장 실패 또는 쓰기 비활성 상태를 UI에 표시
- 관련 문서와 플랫폼 동등성 현황 갱신

## 제외 범위

- 마우스 겹침 투명화 감지
- 오버레이 드래그와 다중 모니터 위치 복원
- 이동, 행동, 말풍선 설정 편집기와 런타임
- 시스템 트레이와 로그인 시 실행

## 열린 질문

- 없음

## 결정사항

- `App`이 현재 typed `AppSettings`의 단일 소유자가 되고, 저장 성공 후 오버레이에 같은 값을 적용한다.
- `overlay.width`는 펫 콘텐츠 너비로 사용하고 높이는 현재 패키지 기본 모션 첫 프레임의 종횡비로 계산한다.
- 슬라이더는 조작 중 즉시 미리보기하되 파일 저장은 조작 종료 시 수행한다.
- Windows에서 아직 구현하지 않은 화면 식별자와 원점은 이번 변경에서 보존만 한다.
