# 앱 내 간단 이용 가이드

## 상태

- 상태: in_progress
- 생성일: 2026-09-05
- 마지막 갱신: 2026-09-05

## 목표

- 웹 설명서를 복제하지 않고 앱에서 첫 작업 순서와 핵심 용어를 빠르게 이해할 수 있는 짧은 이용 가이드를 제공한다.
- macOS에서 확정한 정보 구조와 문구를 Windows 네이티브 설정 화면에 동등하게 적용할 수 있도록 인계한다.

## 범위

- macOS 설정 사이드바의 `지원 > 이용 가이드` 진입점
- 내 펫 준비, 애니메이션, 행동, 평상시 행동, 화면 표시·이동·상호작용·말풍선·규칙 설정의 작업 순서 안내
- `애니메이션`, `행동`, `평상시 행동`, `규칙`의 짧은 용어 설명
- 관련 설정 화면 바로가기와 고정 운영 웹 가이드 연결
- 접근성 식별자와 설정 UI 스모크 테스트
- 제품 결정, 플랫폼 동등성, Windows 네이티브 구현·QA 인계

## 제외 범위

- 첫 실행을 막는 강제 온보딩과 가이드 완료 상태 저장
- 웹 가이드 콘텐츠와 서버 구현
- 설정 schema, `.monglepet` package와 제작자 설정 schema 변경
- 앱 버전 상승, 커밋·푸시와 릴리스

## 열린 질문

- 없음

## 결정사항

- 가이드는 언제든 다시 열 수 있는 설정 목적지이며 첫 실행 시 자동으로 띄우지 않는다.
- 앱 안에는 핵심 순서와 용어만 두고 상세 제작·배포 설명은 웹 가이드로 연결한다.
- 가이드의 바로가기는 현재 선택 펫과 저장 설정을 바꾸지 않고 설정 목적지만 이동한다.
- Debug·Release 모두 운영 웹 `https://mapleroom.kr/monglepet/guide`를 연다.

## 검증 방법

- 설정 사이드바에서 `지원 > 이용 가이드`를 선택해 화면을 열 수 있는지 확인한다.
- 내 펫, 펫 정보·애니메이션, 행동 편집, 평상시 행동, 화면 표시, 이동과 규칙 설정 바로가기가 올바른 목적지로 이동하는지 확인한다.
- 애니메이션과 행동의 차이, 평상시 fallback과 조건 규칙 우선 적용 설명이 현재 제품 계약과 일치하는지 확인한다.
- Debug·Release에서 고정 운영 웹 가이드 URL을 여는지 확인한다.
- 기존 설정과 선택 펫 데이터가 바뀌지 않는지 확인한다.
- 관련 UI 테스트 소스, 전체 macOS 단위 테스트, Debug 빌드와 `git diff --check`를 실행한다.

## 남은 위험 / 후속 작업

- 실제 macOS 좁은 창·키보드·VoiceOver QA가 필요하다.
- 현재 호스트의 XCUITest Runner가 앱 assertion 전에 멈추므로 실행 환경을 복구하거나 사용자 수동 QA로 가이드 진입·바로가기·스크롤을 확인해야 한다.
- Windows 실제 접근성·DPI QA 전에는 플랫폼 동등 완료로 표시하지 않는다.
