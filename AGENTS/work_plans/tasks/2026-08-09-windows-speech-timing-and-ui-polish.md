# Windows 말풍선 타이밍과 설정 UI 다듬기

## 상태

- 상태: in_progress
- 생성일: 2026-08-09
- 마지막 갱신: 2026-08-09

## 목표

- macOS 기준대로 말풍선 간격을 늘리면 고정 길이 꼬리와 말풍선 본체가 함께 이동하게 한다.
- 말풍선 XAML Island가 실제 본체 높이로 표시되고 설정 미리보기의 대체 펫 아이콘이 이미지 뒤에 남지 않게 한다.
- 서로 다른 atlas의 행동 전환에서 투명 프레임이 끼지 않게 한다.
- 주기 간격 변경을 즉시 확정·저장하고 기존 예약을 취소한 뒤 새 간격으로 다시 예약한다.
- 행동 대사가 다음 대사까지 유지되는 상황에서도 주기 대사가 멈추지 않게 한다.
- 설정 화면의 카드·간격·행동 단계 입력을 더 부드럽고 읽기 쉽게 정돈한다.
- 설정 콘텐츠가 넓은 창의 왼쪽 좁은 열에 몰리지 않도록 중앙 반응형 폭과 탭별 시각적 헤더를 적용한다.

## 원인

- 직전 보완에서 설정 `gap`을 고정 13px 꼬리 길이에 더해 꼬리가 늘어났으나, macOS의 원래 동작은 꼬리 길이를 유지하고 말풍선 전체를 이동하는 방식이다.
- Windows 말풍선은 호스트에 연결되지 않은 XAML 요소를 측정해 `DesiredSize`가 0이 되었고, clamp 결과 네이티브 HWND 높이가 1px로 생성됐다.
- 설정 미리보기는 자산 로드 성공 뒤에도 펫 대체 `FontIcon`을 숨기지 않아 투명 이미지 뒤로 비쳤다.
- 선택 펫은 행동별로 서로 다른 PNG atlas를 사용하며 기존 재생기는 새 surface 디코딩 전에 현재 brush를 비워 행동 경계에서 캐릭터가 사라졌다.
- 주기 간격 `NumberBox`는 텍스트 편집 중 값 확정이 늦고 Enter 후에도 포커스를 유지해 runtime 갱신이 지연된 것처럼 보인다.
- `다음 대사까지 유지` 행동 대사는 주기 예약을 만들지 않으며, 기존 주기 callback도 같은 행동 대사가 활성 상태면 재예약 없이 종료한다.
- 행동 단계의 애니메이션 ComboBox에는 레이블이 없고 반복 NumberBox만 Header가 있어 높이와 선택 영역이 어긋난다.

## 완료 조건

- 꼬리를 켠 상태에서 간격 0~64px을 바꿔도 꼬리 높이는 고정되고 말풍선 본체와 꼬리가 함께 이동한다.
- 짧은 대사도 말풍선 HWND가 1px로 줄지 않고 본체·글자·꼬리가 모두 보인다.
- 행동마다 atlas가 달라도 새 surface 로드 중 이전 프레임을 유지하고 빈 프레임을 표시하지 않는다.
- 주기 간격을 바꾸면 이전 예약이 취소되고 새 간격이 즉시 예약된다.
- Enter로 주기 시간을 확정하면 숫자 입력 포커스가 빠지고 저장된 값과 runtime이 함께 갱신된다.
- 주기 대사가 하나 이상 있고 말풍선·주기 대사가 켜져 있으면 행동 대사 표시 방식과 관계없이 다음 주기 대사가 예약된다.
- 행동 단계의 애니메이션과 반복 횟수가 같은 높이·명확한 레이블로 표시된다.

## 남은 위험

- 혼합 DPI에서 고정 꼬리와 화면 가장자리 clamp는 실제 다중 모니터 환경에서 추가 확인한다.
- WinUI `NumberBox` 내부 텍스트 편집 동작은 실제 키보드 입력으로 확인한다.

- 2026-08-09: 첫 보완에서는 기본 13px 꼬리에 설정 간격을 더했으나, 후속 사용자 피드백과 macOS 원본 비교 결과 제품 기준과 달라 아래 고정 꼬리 방식으로 되돌렸다.
- 2026-08-09: `다음 대사까지 유지` 행동 대사도 주기 타이머를 예약하고 주기 callback이 해당 대사를 교체하도록 수정했다.
- 2026-08-09: 유지형 행동 대사의 주기 규칙은 macOS runtime에도 같은 의미로 반영했다. 실제 말풍선·설정 미리보기의 가변 꼬리 변경은 후속 비교에서 원래 고정 꼬리 구현으로 복원했다. macOS 빌드 실행은 Windows 환경이므로 후속 macOS 검증으로 남겼다.
- 2026-08-09: 주기 간격 설정 변경 시 기존 예약을 취소하고 새 간격을 사용하는 회귀 테스트를 추가했다. Enter 입력은 값을 확정한 뒤 다음 컨트롤로 포커스를 이동한다.
- 2026-08-09: 최상위 설정 카드는 16px, 하위 카드는 12px 모서리와 얇은 경계·여유 있는 패딩을 사용하도록 정리했다. 행동 단계는 번호 badge, 애니메이션·반복 횟수 레이블과 같은 높이의 입력, 묶인 순서 버튼으로 재구성했다.
- 2026-08-09: Settings 58개를 포함한 Windows 전체 167개 테스트, x64 Debug·Release 빌드와 1.0.0.8 MSIX 생성을 통과하고 개발 패키지 상태 `Ok`를 확인했다.
- 2026-08-09: 실제 QA에서 Compact NumberBox 포커스 고착, notification area 메뉴 뒤 설정창 활성화 실패와 설정이 정상 저장된 상태에서도 주기 말풍선이 표시되지 않는 문제를 재접수했다. 선택 펫 설정에는 말풍선·주기 사용, 5초 간격과 주기 대사 1개가 정상 저장돼 있어 runtime scheduler·표시 경계를 후속 수정한다.

## 완료 결과

- 말풍선 꼬리는 macOS 기준의 고정 길이를 유지하며 간격에 따라 본체와 함께 이동하도록 수정했다.
- 말풍선 본체 클리핑과 설정 미리보기의 중복 대체 아이콘을 수정했다.
- 서로 다른 atlas 사이 행동 전환에서 이전 프레임을 유지해 투명 번쩍임을 제거했다.
- 주기 간격 입력의 값 확정과 runtime 재예약 경계를 명확히 했다.
- 설정 전체의 카드 인상과 행동 단계 선택 UI를 부드럽고 일관되게 정돈했다.
- 설정창은 창 폭에 맞춰 중앙에서 확장되며 탭 헤더와 카드가 같은 읽기 축을 사용한다.
- 실제 키보드·혼합 DPI 결과는 등록된 1.0.0.13 앱에서 사용자 QA로 확인한다.
- 설정창의 밝은 테마·최소 창 폭 최종 육안 결과는 등록된 1.0.0.13 앱에서 사용자 QA로 확인한다.
