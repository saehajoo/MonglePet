## 결정사항

- 자동 제안 경계의 고유한 X·Y 셀 배치를 기준으로 행과 열을 추론한다.
- 자동 제안이 불규칙하거나 한 장 전체뿐이면 안전한 기본값으로 폴백한다.
- 클릭 순서 모드로 전환하면 기존 선택을 비우고 이후 클릭 순서를 재생 순서로 사용한다.
- 전체 선택은 어느 모드에서도 화면 읽기 순서를 사용한다.
- 프레임 지속 시간의 저장 범위 16~60,000ms는 변경하지 않는다.
- AI 제작 안내는 앱이 아닌 `https://mapleroom.kr/monglepet/guide` 웹페이지에서 제공한다.
- crop은 원본에서 가져올 픽셀 범위로만 사용하고 최종 펫 크기·위치는 공통 캔버스 배치와 분리한다.
- crop과 배치 결과는 저장 atlas에 반영하며 `.monglepet` manifest schema와 외부 패키지 계약은 변경하지 않는다.
- 서로 다른 crop 크기의 자동 맞춤은 프레임마다 다른 배율을 만들지 않고 한 가져오기 묶음의 공통 기준 배율을 사용한다.
- 투명 픽셀 경계는 원본 PNG당 한 번만 분석하고, 드래그 중에는 고정 좌표계의 경량 미리보기를 사용한 뒤 종료 시 최종 캔버스를 갱신한다.
