# Windows 로컬 가져오기 검토와 내보내기

## 상태

- 상태: completed
- 생성일: 2026-08-09
- 마지막 갱신: 2026-08-09

## 목표

- `.monglepet`을 설치하기 전에 펫 정보와 권장 설정을 검토하고 적용 여부를 선택하게 한다.
- 현재 설치 펫을 안전한 `.monglepet` ZIP으로 내보내고 선택적으로 권장 프로필을 포함한다.

## 범위

- 패키지 메타데이터·모션 수·권장 프로필 검토 모델
- 권장 프로필 schema-v1~v7 읽기·v7 쓰기와 설치 UUID용 로컬 프로필 변환
- 신규·중복 교체/별도 설치에서 권장 설정 선택 적용
- canonical manifest·참조 이미지와 선택 권장 프로필만 포함하는 원자적 내보내기
- WinUI 검토 대화상자와 Windows 파일 열기·저장 선택기
- 대상 단위 테스트와 문서 갱신

## 제외 범위

- 웹 카탈로그·업로드와 네트워크 공유
- 내장 bundled 펫 내보내기
- 실제 파일 대화상자 수동 QA와 플랫폼 교차 왕복 전체 회귀

## 열린 질문

- 없음

## 결정사항

- 기존 schema-v10 mapper의 검증 규칙을 재사용하되 권장 프로필은 독립 schema-v7 문서로 인코딩한다.
- 검토 이후 설치는 검토한 원본의 변경 여부를 다시 확인한다.
- 내보내기는 설치 폴더 전체가 아니라 canonical manifest와 참조 자산만 staging에 구성해 재검증한다.

## 작업 순서

- [x] 1단계: 명세·macOS 기준 분석
- [x] 2단계: 권장 프로필 codec·검토 모델
- [x] 3단계: 안전한 내보내기 서비스
- [x] 4단계: 가져오기 검토·권장 설정 적용 UI
- [x] 5단계: 내보내기 검토·저장 UI
- [x] 6단계: 대상 테스트·Debug 빌드·문서 갱신

## 검증 방법

- 권장 프로필 v1~v7 호환, v7 왕복과 잘못된 선택 데이터 격리
- 검토 후 원본 변경 거부, 신규·별도·교체 프로필 적용 경계
- canonical 파일 목록, marker·미참조 파일 제외, 목적지 원자적 교체와 왕복 로드
- 대상 xUnit과 x64 Debug 앱 빌드

## 진행 로그

- 2026-08-09: PET_PACKAGE 명세와 macOS 검토·공유 흐름 분석을 시작했다.
- 2026-08-09: 권장 프로필 schema-v1~v7 codec, SHA-256 원본 재확인과 선택 데이터 격리를 구현했다.
- 2026-08-09: canonical manifest·참조 자산만 staging하고 ZIP 왕복 검증 후 목적지를 원자적으로 교체하는 exporter를 구현했다.
- 2026-08-09: WinUI 가져오기·중복 교체·내보내기 검토, 권장 설정 선택, 공유 권한 확인과 파일 저장 선택기를 연결했다.
- 2026-08-09: Settings 50개와 PetLibrary 14개 대상 테스트, x64 Debug 앱 빌드가 통과했다.
- 2026-08-09: 구현 완료 후 Debug·Release 전체 153개 테스트, Release 전체 빌드와 MSIX 생성을 통과했다.

## 완료 결과

- 설치 전 메타데이터·모션·권장 설정을 검토하고 펫만 설치하거나 권장 설정을 설치 UUID의 로컬 프로필로 적용한다.
- 교체는 기존 로컬 프로필을 기본 보존하며 별도 설치는 검토 단계의 권장 설정 선택을 유지한다.
- 내보내기는 marker와 미참조 파일을 제외하고 선택한 권장 설정만 포함하는 검증된 `.monglepet`을 만든다.

## 남은 위험 / 후속 작업

- 실제 Windows 파일 선택·저장 대화상자와 macOS 교차 왕복 수동 QA가 필요하다.
