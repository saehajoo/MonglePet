# 호버 쓰다듬기 상호작용

## 상태

- 상태: done
- 생성일: 2026-07-29
- 마지막 갱신: 2026-07-29

## 목표

- 펫 클릭 대신 실제 표시 영역에 마우스를 잠시 올리면 쓰다듬기 애니메이션을 한 번 재생한다.
- 클릭 통과 상태에서도 같은 상호작용을 제공한다.
- 자동 이동 중에도 포인터가 직접 펫에 진입하면 쓰다듬을 수 있게 하고, 펫 이동이나 프레임 변화만으로는 잘못 인식되지 않게 한다.

## 범위

- 기존 알파 영역 포인터 감시 생명주기에 호버 진입·머무름·이탈 상태 추가
- 쓰다듬기 애니메이션이 설정된 경우에만 저빈도 감시 활성화
- 클릭 쓰다듬기 제거와 드래그 동작 유지
- 자동 이동 중 포인터 주도 호버 허용과 정지 포인터·사용자 드래그 오입력 억제
- 행동 명세, 아키텍처와 제품 결정 동기화
- 단위 테스트와 Debug 빌드

## 제외 범위

- 호버 대기 시간을 사용자 설정으로 노출
- 클릭 통과 전용 쓰다듬기 켜기·끄기 옵션
- 쓰다듬기 애니메이션 선택 방식이나 저장 schema 변경
- 연속 호버 중 반복 재생

## 열린 질문

- 없음

## 결정사항

- 실제 표시 픽셀에 포인터가 진입한 뒤 300ms 머무르면 한 번 실행한다.
- 한 번 실행한 뒤에는 포인터가 펫 패널 밖으로 나가야 다시 활성화한다.
- 자동 이동 중에도 포인터가 직접 표시 영역에 진입하면 실행한다. 포인터가 움직이지 않은 채 펫이 이동해 겹친 경우와 사용자 드래그 중에는 실행하지 않는다.
- 기존 100ms 포인터 감시 timer를 겹침 투명화와 공유하며, 둘 다 필요 없으면 timer를 중지한다.
- 동작 줄이기는 겹침 투명화 전환만 억제하고 기존 쓰다듬기 상호작용 자체는 막지 않는다.

## 작업 순서

- [x] 1단계: 관련 포인터·이동·쓰다듬기 생명주기와 테스트를 확인한다.
- [x] 2단계: 공유 포인터 관찰값과 호버 쓰다듬기 상태 모델을 구현한다.
- [x] 3단계: 클릭 제거, 자동 이동·설정 연결과 문서 갱신을 완료한다.
- [x] 4단계: 관련 단위 테스트, 전체 단위 테스트와 Debug 빌드를 실행한다.

## 검증 방법

- 포인터 진입 직후에는 실행하지 않고 300ms 연속 호버 후 한 번만 실행하는지 확인한다.
- 계속 올려둔 동안 반복하지 않고 패널 이탈 후 다시 진입해야 재실행하는지 확인한다.
- 클릭 통과와 무관하게 작동하고 쓰다듬기 미지정 시 감시 timer가 남지 않는지 확인한다.
- 자동 이동 중 포인터 주도 진입은 실행하고, 정지 포인터 아래로 펫이 이동한 경우·사용자 드래그·재우기와 화면 사용 불가 상태에서는 실행하지 않는지 확인한다.
- 겹침 투명화의 기존 알파 영역, 동작 줄이기와 기본 투명도 복원이 유지되는지 확인한다.

## 완료 결과

- 클릭 대신 실제 표시 픽셀에 300ms 머무르면 쓰다듬기를 한 번 실행하고, 클릭 통과 중에도 같은 동작을 제공한다.
- 자동 이동 중 포인터 주도 쓰다듬기는 허용하고, 사용자 드래그와 정지 포인터 아래로 펫이 이동한 경우를 억제하며 패널 이탈 뒤에만 다음 입력을 허용한다.
- 겹침 투명화와 포인터 감시를 공유하며 두 기능이 모두 필요 없으면 timer를 중지한다.
