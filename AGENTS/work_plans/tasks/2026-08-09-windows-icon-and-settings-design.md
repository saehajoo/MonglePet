# Windows 아이콘과 설정 디자인 정렬

## 상태

- 상태: completed
- 생성일: 2026-08-09
- 마지막 갱신: 2026-08-09

## 목표

- MonglePet 발바닥 정체성을 사용하는 Windows 앱 아이콘을 제공한다.
- macOS 설정 화면의 6개 기능 탭 구조를 Windows WinUI 설정 화면에 반영한다.
- 개발 패키지 등록을 갱신해 로그인 자동 실행 항목을 Windows가 인식하게 한다.

## 범위

- Windows MSIX·실행 파일·시작 메뉴용 이미지와 ICO 자산
- `MainPage`의 탐색 구조와 섹션 표시 전환
- Release 패키지 빌드와 현재 사용자 개발 패키지 재등록

## 제외 범위

- macOS 앱 아이콘 자산 추가
- 설정 데이터 스키마와 런타임 동작 변경

## 열린 질문

- 없음

## 결정사항

- macOS `TabView`의 순서인 펫, 일반, 이동, 행동 루틴, 말풍선, 자동 규칙을 유지한다.
- Windows에서는 같은 정보 구조를 WinUI `NavigationView`의 상단 탐색으로 표현한다.
- 아이콘은 캐릭터 얼굴 대신 크림색 발바닥과 민트색 배경을 사용한다.
- 기존 개발 패키지의 LocalState를 보존하는 업데이트 등록을 위해 패키지 수정 버전을 1.0.0.1로 올린다.

## 작업 순서

- [x] 1단계: 발바닥 원본에서 Windows 패키지용 아이콘 자산 생성
- [x] 2단계: 설정 화면을 6개 상단 탐색 섹션으로 재구성
- [x] 3단계: 관련 테스트와 Debug·Release 패키지 빌드 검증
- [x] 4단계: 개발 패키지를 재등록하고 자동 실행 항목 확인

## 검증 방법

- Windows 테스트 전체 실행
- x64 Debug 앱 빌드
- x64 Release MSIX 패키지 생성
- 현재 사용자 패키지 재등록 후 앱 실행 및 시작 항목 UI 확인

- 2026-08-09: macOS 설정 `TabView` 구조와 Windows 현재 단일 스크롤 구조를 비교했다.
- 2026-08-09: 같은 1.0.0.0 개발 패키지 재등록이 차단되어, 제거 대신 데이터가 보존되는 1.0.0.1 업데이트 등록을 선택했다.
- 2026-08-09: x64 Debug 빌드와 전체 153개 테스트가 통과했다.
- 2026-08-09: 1.0.0.1 Release MSIX를 생성하고 개발 패키지 업데이트 등록, 시작 메뉴 AppID와 등록 상태 `Ok`를 확인했다.
- 2026-08-09: 작업 표시줄이 EXE의 기본 회색 창 아이콘을 사용하는 것을 추출 검사로 확인하고, 실행 파일 내장 아이콘과 AppWindow 절대 아이콘 경로 보완을 시작했다.
- 2026-08-09: Release EXE에서 추출한 32px 아이콘이 발바닥으로 바뀐 것을 확인하고 1.0.0.2 MSIX 생성·개발 패키지 업데이트 등록·재실행을 완료했다.
- 2026-08-09: 시작 메뉴 실행 후 작업 표시줄 아이콘이 여전히 회색이라는 실제 QA 결과에 따라 `SetTaskbarIcon` 전용 API와 활성화 후 재적용을 추가했다.
- 2026-08-09: 1.0.0.3 Release MSIX 빌드, 개발 패키지 업데이트 등록과 시작 메뉴 AppID 재실행을 완료했고 새 프로세스 응답 상태를 확인했다.
- 2026-08-09: 실제 캡처에서 WinUI 기본 회색 창 아이콘을 확인해 HWND `WM_SETICON` 큰·작은 아이콘 직접 설정 보완을 시작했다.
- 2026-08-09: 1.0.0.4 Release 빌드·개발 패키지 업데이트 등록·시작 메뉴 AppID 실행을 완료하고 새 프로세스 응답을 확인했다.

- 2026-08-09: 모든 PNG를 loose 출력에 복사하는 1.0.0.5 Release를 빌드·등록하고 설치 위치의 Square44 후보 3개, 패키지 상태 `Ok`, 아이콘 캐시 새로 고침과 재실행을 확인했다.

## 완료 결과

- 민트색 둥근 타일 위 크림색 발바닥을 Windows 전체 아이콘 자산에 적용했다.
- 설정 화면을 펫, 일반, 이동, 행동 루틴, 말풍선, 자동 규칙 상단 탐색으로 분리했다.
- `MonglePetStartupTask`, 실행 파일 내장 아이콘, AppWindow·HWND 아이콘과 loose 등록용 전체 시각 자산이 포함된 1.0.0.5 개발 패키지를 기존 LocalState를 유지하며 업데이트 등록했다.
- x64 Debug 빌드 0경고·0오류, 전체 153개 테스트 통과, Release MSIX 생성 0오류를 확인했다.
