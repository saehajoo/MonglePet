# 데스크톱 펫과 설치한 펫 역할 분리

## 상태

- 상태: in_progress
- 생성일: 2026-09-01
- 마지막 갱신: 2026-09-01

> D-111 작업 계획 `2026-09-01-my-pets-one-shot-behavior-speech.md`가 사용자 화면을 단일 `내 펫`으로 통합하고 가져오기에서 instance/profile까지 원자적으로 만드는 후속 범위를 담당한다. 이 문서의 installation·instance 내부 분리와 항상 새 installation 결정은 그대로 유효하다.

## 목표

- 설치한 펫 콘텐츠와 데스크톱에서 실행하는 펫 인스턴스의 역할을 사용자 화면에서도 명확히 분리한다.
- 펫을 살펴보거나 가져오는 작업이 현재 데스크톱 펫과 개인 설정을 암묵적으로 교체하지 않게 한다.
- 선택한 데스크톱 펫의 많은 설정을 화면 표시, 평상시 행동, 이동과 상호작용 목적지로 나눠 찾기 쉽게 한다.

## 범위

- macOS 설정 사이드바와 관련 화면 명칭·정보 구조
- 설치한 펫의 독립적인 탐색 선택과 데스크톱 펫 추가 흐름
- 동일 패키지 ID를 포함한 일반 로컬·웹 가져오기의 항상 새 설치 정책
- 데스크톱 펫 제거 시 인스턴스 전용 설정 손실 안내
- 공통 제품 결정·펫 패키지 명세와 Windows 인계 문서

## 제외 범위

- `.monglepet` formatVersion, 권장 프로필 schema와 로컬 settings schema 변경
- 설치 항목의 자동 업데이트 또는 기존 설치 교체 기능
- 제거한 데스크톱 펫의 휴지통·복원 이력
- Windows 소스 수정·빌드·실제 QA

## 결정사항

- `설치한 펫`은 콘텐츠·애니메이션·메타데이터를 관리하는 원본이고 `데스크톱 펫`은 독립 overlay·행동·이동·말풍선 설정을 갖는 실행 인스턴스다.
- 설치한 펫 선택은 탐색·편집 대상만 바꾸며 선택된 데스크톱 펫의 `petKey`를 바꾸지 않는다.
- 일반 가져오기는 같은 패키지 ID 여부와 관계없이 항상 새 installation UUID로 설치한다. 기존 설치 교체는 일반 가져오기 UI에서 제공하지 않는다.
- 데스크톱 펫 제거는 설치 콘텐츠를 남기고 해당 instance와 독립 profile만 삭제한다. 복원되지 않는 개인 설정 범위를 확인 문구에 표시한다.
- 설정 화면은 중첩 가로 탭 대신 macOS sidebar 목적지로 `화면 표시`, `평상시 행동`, `이동`, `상호작용`을 구분한다.
