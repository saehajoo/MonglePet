# Windows 행동 루틴과 자동 규칙 편집기

## 상태

- 상태: completed
- 생성일: 2026-08-09
- 마지막 갱신: 2026-08-09

## 목표

- Windows WinUI에서 현재 펫의 행동 루틴과 자동 규칙 전체 구조를 생성·수정·삭제하고 즉시 저장·재생한다.
- macOS에서 확정한 편집 검증, 삭제 cascade와 기본 루틴 보호 동작을 C# 순수 편집 계층으로 반영한다.

## 범위

- `BehaviorProfile` 순수 편집기와 오류 모델·단위 테스트
- 루틴 생성·삭제, 반복 여부와 단계 추가·삭제·순서 변경
- 단계별 현재 펫 기본 참조·실제 모션 선택과 `repeatCount` 편집
- 앱·입력 없음 자동 규칙 생성·삭제, 사용 여부·우선순위·조건·대상 루틴 편집
- Windows PFN/실행 파일명 직접 입력과 현재 전면 앱 식별자 채우기
- 전체 설정 원자 저장, runtime 즉시 반영과 펫 전환·재실행 복원
- packaged Release 실제 UI QA

## 제외 범위

- 설치 앱 전체 목록·아이콘·표시 이름을 제공하는 고급 앱 선택기
- 복합 조건, 시간대 조건과 규칙 drag-and-drop
- 이동·쓰다듬기·말풍선 설정 편집 UI

## 열린 질문

- 없음

## 결정사항

- 편집은 현재 펫의 `BehaviorProfile`을 순수 편집기로 먼저 검증한 뒤 기존 schema-v10 전체 설정 저장 경계로 한 번에 반영한다.
- 기본 루틴 `__monglepet_default_behavior__`은 삭제할 수 없지만 단계와 반복 여부는 편집할 수 있다.
- 루틴을 삭제하면 해당 루틴을 가리키는 자동 규칙과 행동 대사를 함께 제거하고 수동 선택은 기본 루틴으로 복구한다.
- WinUI는 목록과 선택 항목 편집 폼을 분리하며 각 사용자 동작마다 즉시 저장한다.
- 앱 규칙 직접 입력은 `pfn:` 또는 `exe:` 접두사와 공백 없는 소문자 식별자를 요구하고 현재 감지 중인 전면 앱 식별자를 채울 수 있다.

- 루틴·단계·규칙의 생성·수정·삭제·한계·잘못된 참조와 cascade를 xUnit으로 확인한다.

## 완료 결과

- 현재 펫의 루틴과 단계, 앱·입력 없음 자동 규칙을 WinUI만으로 생성·수정·삭제하고 즉시 저장·재생할 수 있다.
- 기본 루틴 보호와 루틴 삭제 시 규칙·행동 대사 cascade, 최소 한 단계와 항목 한계를 UI와 독립된 편집 계층에서 검증한다.
- 현재 감지 중인 Windows PFN/실행 파일명 식별자를 채우거나 직접 입력할 수 있으며 창 제목·경로·입력 내용은 저장하지 않는다.
- 실제 packaged Release에서 `rest×2 → focus×3`, 비반복 루틴과 PFN 규칙을 만든 뒤 완전 종료·재실행해 같은 설정과 실행 결과를 복원했다.
