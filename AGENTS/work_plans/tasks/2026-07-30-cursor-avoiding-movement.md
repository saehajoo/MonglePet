# 마우스 도망가기 이동 모드

## 상태

- 상태: completed
- 생성일: 2026-07-30
- 마지막 갱신: 2026-07-30

## 목표

- 마우스가 설정 거리 안으로 접근하면 펫이 반대 방향의 안전한 위치로 이동하는 독립 이동 모드를 제공한다.
- 평상시에는 사용자가 선택한 대로 가만히 있거나 자유 이동하고, 도망 중에는 별도 방향 애니메이션을 표시한다.
- 클릭 통과와 겹침 투명화는 기존 전역 표시 설정을 유지하되 도망가기 모드에서는 쓰다듬기를 실행하지 않는다.

## 범위

- `cursorAvoiding` 이동 모드와 평상시 행동 `stationary` / `freeRoaming`
- 마우스 감지 거리, 도망 속도와 공통·방향별 도망 애니메이션
- 이동 범위와 다중 모니터를 고려한 도망 목표 및 상태 전환
- settings schema-v6와 schema-v5 순차 마이그레이션
- 권장 프로필 schema-v3와 schema-v1·v2 호환 읽기
- 설정 UI, 내보내기·가져오기 공통 요약과 모션 참조 편집
- 도망가기 모드의 쓰다듬기 감지·실행 차단

## 제외 범위

- 포인터 이동 이력 저장 또는 분석
- 클릭 통과 설정의 자동 변경
- 도망 경로의 충돌·중력 등 물리 시뮬레이션
- 감지 거리와 별도로 노출하는 사용자 조절 해제 거리

## 열린 질문

- 없음

## 결정사항

- 도망가기는 위치 고정이나 자유 이동의 토글이 아니라 네 번째 독립 이동 모드로 제공한다.
- 평상시 행동은 도망가기 모드 안에서 `가만히 있기` 또는 `자유 이동` 중 선택한다.
- 마우스와의 거리는 펫 표시 사각형까지의 최단 거리로 판단하고, 해제 거리는 감지 거리보다 크게 내부 계산한다.
- 도망 목표는 마우스 반대 방향을 우선하되 이동 범위에 막히면 허용 영역의 후보 중 마우스와 가장 멀어지는 위치를 선택한다.
- 도망가기 모드에서는 쓰다듬기 UI를 비활성화하고 감지 및 실행 경계에서도 차단한다.
- 클릭 통과와 겹침 투명화는 기기별 전역 표시 설정으로 그대로 유지한다.
