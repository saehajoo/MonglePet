# 입력 없음 규칙 즉시 해제

## 상태

- 상태: completed
- 생성일: 2026-07-31
- 마지막 갱신: 2026-07-31

## 목표

- 입력 없음 규칙이 활성화된 뒤 사용자 입력이 다시 감지되면 기존 애니메이션 사이클을 기다리지 않고 다음 행동으로 전환한다.

## 범위

- 입력 없음 규칙의 3초 이탈 지연 제거
- 활동 polling에서 입력 재개가 확인된 다음 snapshot의 즉시 행동 결정
- 자동 규칙과 행동 런타임 회귀 테스트
- 행동 명세, 결정 기록과 테스트 문서 동기화

## 제외 범위

- 1초 활동 polling 주기 변경
- 입력 event tap 또는 접근성 권한 추가
- 하나의 행동 루틴 안에서 애니메이션 단계가 전체 사이클을 재생하는 규칙 변경
- 쓰다듬기와 이동 애니메이션의 표시 우선순위 변경

## 열린 질문

- 없음

## 결정사항

- 입력 없음 규칙 진입은 설정된 시간 임계값을 그대로 사용한다.
- 입력 재개는 다음 1초 polling snapshot에서 확인되는 즉시 규칙을 해제한다.
- 일반 행동이 바뀌면 최신 루틴의 첫 단계·첫 프레임으로 교체하는 기존 정책을 적용한다.

## 작업 순서

- [x] 1단계: 입력 없음 이탈 지연 상태 제거
- [x] 2단계: Resolver와 Runtime 회귀 테스트 추가
- [x] 3단계: 전체 단위 테스트, Debug 빌드와 문서 동기화

## 검증 방법

- 입력 없음 규칙 진입 직후 입력 시간이 0으로 바뀐 snapshot에서 기본 행동을 선택하는지 확인
- 입력 없음 행동의 애니메이션 사이클 도중 입력이 재개되어도 즉시 다른 행동으로 교체되는지 확인
- 전체 `MonglePetTests`와 Debug 빌드

## 진행 로그

- 2026-07-31: 일반 행동 전환기는 이미 즉시 교체하지만 입력 없음 Resolver가 별도 3초 이탈 지연으로 이전 결정을 유지하는 원인을 확인했다.
- 2026-07-31: Resolver의 이탈 지연 상태를 제거하고 입력 재개 snapshot에서 즉시 다음 규칙 또는 기본 행동을 선택하도록 변경했다.
- 2026-07-31: 입력 없음 규칙 해제와 애니메이션 사이클 도중 교체 회귀 테스트, 전체 단위 테스트와 Debug 빌드를 통과했다.
