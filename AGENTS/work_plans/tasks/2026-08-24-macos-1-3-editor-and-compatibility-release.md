# macOS 1.3 편집기·호환성 안내 Preview 릴리스

## 상태

- 상태: in_progress
- 생성일: 2026-08-24
- 마지막 갱신: 2026-08-24

## 목표

- 새 내장 몽글이를 포함한 macOS 다음 Preview를 `1.3.0 (5)`로 완성한다.
- 최소 앱 버전이 높은 펫도 보안·형식 검증을 통과하면 설치할 수 있게 하고 업데이트는 권장 안내로 제공한다.
- PNG와 스프라이트 시트 제작기의 crop 정확도, 프레임 복사, 확대, 추가 PNG, 좌우·상하 뒤집기를 개선한다.
- macOS 기준 동작과 공통 패키지 fixture를 확정한 뒤 Windows 작업 공간에서 구현할 인계 지침을 남긴다.

## 범위

- 펫 콘텐츠 버전과 앱 호환성 버전의 의미·검증 경계 문서화
- 로컬·웹 펫 가져오기의 최소 앱 버전 비차단 권장 경고와 공식 다운로드 페이지 버튼
- crop 결과 미리보기와 최종 atlas 픽셀 일치
- PNG·스프라이트 편집 확대, 프레임 복사, 편집 중 PNG 추가, 프레임별 좌우·상하 뒤집기
- 새 내장 몽글이 공통 fixture와 Windows 인계 문서
- macOS `1.3.0 (5)` 테스트·빌드·실제 앱 QA·미서명 Preview ZIP 릴리스

## 제외 범위

- 앱 업데이트 가능 여부를 조회하는 네트워크 요청
- 자동 다운로드·자동 설치 또는 Sparkle 같은 자동 업데이트 프레임워크
- 펫 콘텐츠 버전 자동 승격과 정렬 정책
- Windows 소스 변경·빌드·실제 Windows QA
- Developer ID 코드 서명, 공증과 DMG

## 열린 질문

- 없음. 공식 다운로드 페이지는 `https://mapleroom.kr/monglepet/download`로 확정했고 업데이트 확인·자동 업데이트는 보류한다.

## 결정사항

- `manifest.version`은 제작자가 정하는 비어 있지 않은 자유 문자열로 유지하며 한글·영문을 허용하고 앱이 자동 승격하지 않는다.
- `createdWithMonglePetVersion`과 `minimumMonglePetVersion`만 엄격한 `MAJOR.MINOR.PATCH`로 비교한다.
- 최소 앱 버전이 더 높아도 설치를 허용하되 일부 기능이 적용되지 않을 수 있음을 명확히 알리고 공식 다운로드 페이지를 제공한다.
- flip은 `crop → 좌우·상하 변환 → 공통 캔버스 배치` 순서로 최종 atlas에 굽고 패키지 schema는 바꾸지 않는다.
- 다음 macOS Preview는 `1.3.0 (5)`, 후보 태그는 `macos-v1.3.0-preview.1`로 한다.

## 검증 방법

- 최소 앱 버전이 현재 앱보다 높은 로컬·웹 패키지가 경고를 표시하면서 설치 가능하고, 잘못된 버전·형식·보안 위반은 계속 거부되는지 단위 테스트한다.
- 비대칭 픽셀 fixture로 crop·좌우·상하·양축 뒤집기 결과를 검증하고 미리보기와 최종 atlas가 같은 처리 경로를 사용하는지 확인한다.
- PNG 다중 선택·추가, 스프라이트 선택 순서, 확대 상태의 crop·이동, 프레임 복사와 450ms 기본값을 실제 앱에서 확인한다.
- 전체 `MonglePetTests`, 코드서명 없는 Debug·Release 빌드와 격리된 Preview 앱 실행을 수행한다.
- ZIP의 앱 버전·실행·SHA-256을 확인하고 GitHub 릴리스 자산의 크기·digest를 로컬 산출물과 비교한다.

- 2026-08-24: 자유 문자열 펫 버전과 비차단 최소 앱 버전 권장 정책, 공통 내장 펫 fixture, crop→flip→canvas 처리 순서를 명세·결정·Windows 인계에 반영했다.
- 2026-08-24: 전체 `MonglePetTests` 464개 중 463개 통과, 선택형 WebP fixture 1개 건너뜀, 실패 0개를 확인했다. Debug 테스트 빌드와 `arm64`·`x86_64` Universal Release 빌드가 성공했다.
