# 화면 표시·이동 설정 정보 구조 다듬기

## 상태

- 상태: in_progress
- 생성일: 2026-09-05
- 마지막 갱신: 2026-09-05

## 목표

- 이미 분리된 `화면 표시`, `평상시 행동`, `이동`, `상호작용` 목적지는 유지한다.
- 화면 표시의 긴 단일 섹션을 기능별로 구분해 현재 조정 범위를 빠르게 찾을 수 있게 한다.
- 이동 화면에서 현재 방식과 핵심 값을 한눈에 확인하고, 마우스 도망가기의 평상시·도망 상황을 명확히 나눈다.
- 이동 행동 편집을 수치 설정과 구분하되 기존 옵션을 접거나 제거하지 않는다.
- 같은 사용자 결과를 Windows에서 네이티브 UI로 후속 반영할 지침을 남긴다.

## 범위

- macOS `화면 표시`의 크기·표현·마우스 반응 섹션 구분
- macOS `이동`의 현재 설정 요약, 방식별 수치와 행동 영역 구분
- 오래된 설정 안내 문구 수정
- Windows 행동 중심 설정 인계 문서와 플랫폼 현황 갱신

## 제외 범위

- 저장 schema, 패키지·제작자 설정 schema와 런타임 동작 변경
- 옵션 삭제 또는 접는 고급 설정 도입
- 최신 펫과 구버전 앱의 교차 호환성 테스트
- Windows 소스 구현·빌드·실제 QA
- 앱 버전 증가, 커밋·푸시와 릴리스

## 열린 질문

- 없음

## 결정사항

- 선택한 펫 설정의 최상위 사이드바 목적지는 더 늘리지 않는다.
- 화면 표시 옵션은 `크기`, `화면 표현`, `마우스 반응`으로 항상 펼쳐 표시한다.
- 이동 방식 선택 바로 아래에 현재 방식·범위·속도 요약을 표시한다.
- 마우스 도망가기는 `평상시`와 `마우스가 가까울 때`를 별도 섹션으로 구분한다.
- 이동 행동은 방식별 수치와 분리된 `이동할 때 행동` 섹션에 모은다.
