# 조건 규칙 행동 연속 재생

## 상태

- 상태: in_progress
- 생성일: 2026-09-08
- 마지막 갱신: 2026-09-08

## 목표

- 앱 사용·입력 없음 조건이 유지되는 동안 선택한 행동이 마지막 프레임에서 멈추지 않고 전체 단계를 계속 순환하게 한다.
- 일회성·랜덤·이동 등 다른 재생 문맥의 기존 의미를 보존한다.

## 범위

- 앱 사용 규칙과 입력 없음 규칙의 조건 유지 중 연속 행동 재생
- 랜덤 후보가 비었거나 참조가 사라졌을 때 기본 행동의 안전한 연속 재생
- macOS 런타임·설정 안내·단위 테스트
- 행동 명세·제품 결정·플랫폼 동등성·Windows 인계

## 제외 범위

- 행동 단계·저장 `repeats`, settings schema-v16, 제작자 설정 v12와 package format 변경
- 규칙 우선순위, 활동 감지 주기, 이동 좌표·재생 방식과 말풍선 발생 조건 변경
- Windows 소스 구현·빌드·QA
- 앱 버전 증가, 커밋·푸시·릴리스

## 결정사항

- 조건 규칙은 같은 조건이 유지되는 동안 행동의 단계별 `repeatCount`를 모두 소비한 뒤 첫 단계부터 다시 재생한다.
- 조건 해제·상위 규칙 전환은 현재 사이클 완료를 기다리지 않고 기존처럼 즉시 새 결과로 전환한다.
- 평상시 fixed와 기본 fallback은 계속 순환하고, 랜덤의 개별 행동과 쓰다듬기는 한 번만 통과한다. 이동 행동은 실제 이동 중에만 별도 반복한다.
- 같은 규칙 snapshot이 반복 수신되어도 현재 위치를 재시작하지 않는다.

## 검증 방법

- 앱 사용 규칙과 입력 없음 규칙이 두 번 이상 전체 순환
- 같은 규칙 update가 재생 위치를 초기화하지 않음
- 앱 전환·입력 재개 시 즉시 평상시/이동 결과로 복귀
- 랜덤 후보 없음·누락 참조의 기본 행동 연속 재생
- 랜덤 개별 행동·쓰다듬기 1회, 이동 중 반복 회귀
- 관련 단위 테스트, 전체 macOS 단위 테스트, Debug 빌드, `git diff --check`

## 진행 로그

- 2026-09-08: 코드와 D-111·D-115를 대조해 앱·입력 없음 규칙이 의도적으로 한 번 재생 후 마지막 프레임을 유지하고, 규칙 우선순위가 이동보다 높으면 이동도 계속 차단해 펫이 멈춘 것처럼 보이는 원인을 확인했다. 관련 기존 런타임 테스트 50개는 현 정책에서 통과했다.
- 2026-09-08: macOS runtime을 조건 규칙 문맥 반복으로 변경했다. 앱·입력 없음 조건 유지, 같은 snapshot 위치 보존, 조건 해제, 이동 중 pause/resume과 랜덤 후보 누락 fallback을 포함한 관련 테스트 53개가 통과했다.
