# 조건 규칙 행동 연속 재생

## 상태

- 상태: in_progress
- 생성일: 2026-09-08
- 마지막 갱신: 2026-09-08

## 목표

- 앱 사용·입력 없음 조건이 유지되는 동안 선택한 행동이 마지막 프레임에서 멈추지 않고 전체 단계를 계속 순환하게 한다.
- 일회성·랜덤·이동 등 다른 재생 문맥의 기존 의미를 보존한다.

## 범위

- 앱 사용 규칙과 입력 없음 규칙의 조건 유지 중 연속 행동 재생
- 랜덤 후보가 비었거나 참조가 사라졌을 때 기본 행동의 안전한 연속 재생
- macOS 런타임·설정 안내·단위 테스트
- 행동 명세·제품 결정·플랫폼 동등성·Windows 인계

## 제외 범위

- 행동 단계·저장 `repeats`, settings schema-v16, 제작자 설정 v12와 package format 변경
- 규칙 우선순위, 활동 감지 주기, 이동 좌표·재생 방식과 말풍선 발생 조건 변경
- 실제 Windows 앱 QA와 플랫폼 교차 확인
- 앱 버전 증가, 커밋·푸시·릴리스

## 결정사항

- 조건 규칙은 같은 조건이 유지되는 동안 행동의 단계별 `repeatCount`를 모두 소비한 뒤 첫 단계부터 다시 재생한다.
- 조건 해제·상위 규칙 전환은 현재 사이클 완료를 기다리지 않고 기존처럼 즉시 새 결과로 전환한다.
- 평상시 fixed와 기본 fallback은 계속 순환하고, 랜덤의 개별 행동과 쓰다듬기는 한 번만 통과한다. 이동 행동은 실제 이동 중에만 별도 반복한다.
- 같은 규칙 snapshot이 반복 수신되어도 현재 위치를 재시작하지 않는다.

## 검증 방법

- 앱 사용 규칙과 입력 없음 규칙이 두 번 이상 전체 순환
- 같은 규칙 update가 재생 위치를 초기화하지 않음
- 앱 전환·입력 재개 시 즉시 평상시/이동 결과로 복귀
- 랜덤 후보 없음·누락 참조의 기본 행동 연속 재생
- 랜덤 개별 행동·쓰다듬기 1회, 이동 중 반복 회귀
- 관련 단위 테스트, 전체 macOS 단위 테스트, Debug 빌드, `git diff --check`

## 진행 로그

- 2026-09-08: Windows `main`을 `a44b1b2`로 갱신하고 현재 runtime을 대조했다. 규칙 scheduler는 아직 `Once`이며 이동 우선 결과에서는 규칙 scheduler를 정지하므로 조건 유지 반복과 가려진 규칙 pause/resume이 모두 후속 대상이다. 사용자 진행 요청에 따라 Windows 구현을 시작한다.
- 2026-09-08: Windows에 표시 결과와 이동을 제외한 규칙 결과를 함께 계산하는 `BehaviorLayerResolver`를 추가했다. 앱·입력 없음 규칙 scheduler는 같은 요청에서 cursor를 보존하며 전체 행동을 반복하고, 이동 우선 중에는 숨은 규칙 layer를 pause했다가 조건이 유지되면 남은 위치에서 재개한다. 조건·규칙·행동 변경은 새 요청으로 즉시 전환한다.
- 2026-09-08: 랜덤 후보 없음·누락 참조의 기본 행동은 반복하고 랜덤 개별 행동의 1회 의미는 유지했다. 설정 화면에 조건 유지 중 전체 반복 안내를 추가하고 같은 snapshot·조건 해제·이동 우선 pause/resume·fallback을 자동 테스트로 고정했다.
- 2026-09-08: Windows Debug·Release 각각 총 377개 테스트와 경고·오류 없는 전체 빌드를 통과했다. 실제 전면 앱/입력 없음 진입·해제, 짧은 행동 3회 이상, 이동 우선 전환과 말풍선 중복 여부의 오버레이 QA는 남겼다.
- 2026-09-08: 사용자 승인에 따라 편집 보호와 함께 Windows `1.9.1.23`, 태그 `windows-v1.9.1-preview.1`로 게시 준비했다. 미서명 x64 설치기 생성과 기존 버전 위 데이터 보존 업데이트·설치본 응답을 통과했으며 실제 장기 오버레이 QA는 계속 남긴다.
- 2026-09-08: 코드와 D-111·D-115를 대조해 앱·입력 없음 규칙이 의도적으로 한 번 재생 후 마지막 프레임을 유지하고, 규칙 우선순위가 이동보다 높으면 이동도 계속 차단해 펫이 멈춘 것처럼 보이는 원인을 확인했다. 관련 기존 런타임 테스트 50개는 현 정책에서 통과했다.
- 2026-09-08: macOS runtime을 조건 규칙 문맥 반복으로 변경했다. 앱·입력 없음 조건 유지, 같은 snapshot 위치 보존, 조건 해제, 이동 중 pause/resume과 랜덤 후보 누락 fallback을 포함한 관련 테스트 53개가 통과했다.
- 2026-09-08: 전체 `MonglePetTests` 587개 중 586개가 성공했고 외부 로컬 WebP fixture 선택형 1개만 건너뛰었다. 실패는 없으며 코드 서명 없는 Debug 빌드와 `git diff --check`가 통과했다.
