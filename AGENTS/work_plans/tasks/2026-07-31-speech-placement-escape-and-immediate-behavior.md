# 말풍선 배치·다중 화면 도망·즉시 행동 전환

## 상태

- 상태: completed
- 생성일: 2026-07-31
- 마지막 갱신: 2026-07-31

## 목표

- 펫별 말풍선 위치를 펫 기준 상대값으로 조정하고 화면 밖 배치를 자동 보정한다.
- 마우스 도망가기의 평상시 `가만히 있기`에서도 허용된 인접 화면으로 도망갈 수 있게 한다.
- 일반 행동이 달라지거나 현재 행동 정의가 편집되면 이전 애니메이션 사이클을 기다리지 않고 최신 행동으로 전환한다.

## 범위

- 말풍선 선호 위치 `자동 / 위 / 아래`, 좌우 오프셋과 펫 사이 간격
- 실제 말풍선 배치에 맞춰 펫을 향하는 꼬리 위치 계산
- 앱 설정 schema-v10과 권장 프로필 schema-v7 저장·복원·마이그레이션
- 전체 허용 화면을 고려하는 커서 도망 경로와 기존 이동 범위 우선 적용
- 일반 행동의 즉시 교체와 일회성 상호작용·실제 이동 표시 우선순위 유지
- 관련 명세, 결정 기록, 테스트 갱신

## 제외 범위

- 화면 절대 좌표로 말풍선 위치 저장
- 말풍선을 펫의 좌우에 배치하는 새 꼬리 방향
- 쓰다듬기 일회성 애니메이션을 일반 행동 변경으로 중단
- 이동 중 애니메이션을 일반 행동으로 덮어쓰기

## 열린 질문

- 없음

## 결정사항

- 말풍선 배치는 시각 테마와 분리된 펫별 상대 설정으로 저장한다.
- 현재 화면 안에서 포인터와 충분히 멀어질 수 있으면 그 화면 안에서 이동하고, 화면 경계에 막힌 경우에만 포인터 반대 방향의 허용 화면 후보를 사용한다.
- 다른 행동 ID와 같은 행동 ID의 편집본 모두 즉시 첫 단계·첫 프레임부터 시작한다. 동일한 행동 값의 반복 요청은 재시작하지 않는다.
- 일회성 상호작용과 실제 이동 표시는 기존 우선순위를 유지하며, 그동안 들어온 최신 일반 행동은 우선 표시가 끝날 때 사용한다.

## 검증 방법

- 앱 설정 schema-v9→v10 마이그레이션과 v10 왕복 테스트
- 권장 프로필 schema-v6 호환과 schema-v7 왕복 테스트
- 말풍선 자동·위·아래, 오프셋, 화면 경계와 음수 좌표 화면 테스트
- 좌우로 붙은 화면, 화면 사이 간격, 선택 화면·사용자 지정 영역의 도망 경로 테스트
- 다른 행동, 같은 ID 편집 행동, 동일 요청과 쓰다듬기 중 최신 행동 교체 테스트
- 관련 단위 테스트 후 Debug 빌드

## 완료 결과

- 말풍선 위치는 펫별로 자동·위·아래, 좌우 오프셋과 간격을 설정할 수 있으며 저장·공유·재적용된다.
- 현재 화면 경계 보정과 사용자 꼬리 정렬을 함께 보존하고, 위치 보정이 필요한 경우에만 꼬리가 실제 펫 중심을 향한다.
- 정지형 마우스 도망가기는 허용된 인접 화면으로 이동할 수 있고 제한 범위는 계속 우선한다.
- 행동·애니메이션 편집 및 자동 규칙 전환은 다음 사이클을 기다리지 않고 즉시 표시 기준을 갱신한다.
- 말풍선 설정 화면과 편집 시트에서 현재 펫과 말풍선의 상대 위치를 같은 정지 미리보기로 확인할 수 있다.
