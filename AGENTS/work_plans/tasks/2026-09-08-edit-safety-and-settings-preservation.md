## 목표

- 행동 삭제가 관계없는 이동 옵션을 변경하지 않도록 한다.
- 삭제 영향, 설정 저장 실패와 미저장 편집 폐기를 사용자가 현재 작업 문맥에서 확인한다.

## 범위

- 행동 삭제 시 독립 이동 모드와 시간 방식 보존, 삭제 참조만 정리
- 행동 삭제 전 실제 규칙·대사·이동·평상시 행동 연결 영향 안내
- 설정창 모든 목적지의 저장 실패 공통 표시 및 현재 설정 재저장
- 큰 제작 편집기의 변경 감지와 닫기·취소 시 폐기 확인 통일
- 관련 회귀 테스트, Debug 빌드와 Windows 인계

## 제외 범위

- 행동 전체 미리보기, 일괄 프레임 편집, 실행취소·영구 백업, 성능 최적화
- 20~30 MiB 최소 앱 버전 정책 변경, WebP, 자동 업데이트
- 앱 버전·schema 증가, 커밋·푸시·릴리스
- 사용자 설치 펫·이미지·실제 설정 파일의 변경

## 결정사항

- 정상 편집은 즉시 반영하고, 저장 실패 시 메모리의 최신 설정을 보존해 사용자가 재시도할 수 있게 한다. 성공으로 숨기거나 원본 파일을 덮는 별도 우회를 만들지 않는다.
- 행동 삭제의 기존 참조 정리 의미는 유지하되 삭제 전에 실제 영향을 설명한다. 무관한 옵션과 다른 펫은 보존한다.
- 미변경 창은 바로 닫고, 변경한 창만 `계속 편집`과 `변경사항 버리기`를 묻는다. 취소한 작업의 원본과 초안을 보호하고 명시적 저장 성공 뒤에는 다시 묻지 않는다.
- settings schema-v16, 제작자 설정 v12와 package format은 변경하지 않는다.

## 열린 질문

- 없음. 직전 분석에서 제안한 첫 작업 묶음을 사용자 진행 요청에 따라 구현한다.

## 남은 위험 / 후속 작업

- 새 기능 후보와 30 MiB 최소 버전 정책은 본 안정화 이후 별도 범위로 다룬다.
- 보호 범위는 각 편집기의 취소·제목바 닫기다. 부모 화면·앱 종료로 자식 수명이 끝나는 기존 즉시 종료는 보호하지 않는다.
- 애니메이션 저장 후 후속 행동 연결 실패처럼 부분 저장이 가능한 기존 경계는 유지한다. 폐기 확인은 아직 저장하지 않은 변경만 버리며 이미 적용된 내용은 유지된다고 안내한다. 말풍선 메모리 적용 후 디스크 실패는 공통 재저장 경로로 복구한다.
- 실제 QA: 편집 후 취소→계속 편집→제목바 닫기→버리기, 미변경·원복 후 즉시 닫기, 저장 성공 때 중복 확인 없음, 행동 삭제 영향/취소, 탭 이동 후 저장 오류·재시도, 좁은 창·VoiceOver를 확인한다.
